# zerogen

## 0.1.0

### Minor Changes

- b96f6d1: First release. `zerogen codegen` generates the same Swift as `zero-swift codegen`, byte for byte, from a `zerogen.json` with the shared `schema` and `export` settings and a `targets.swift` section; `--target swift` selects the target. `zerogen drift record` records the same drift vectors as `zero-swift drift record`. The Rust target isn't implemented yet.
